# 🛒 Git_groceries（我的数字杂货铺）

> *"Need to have everything, scavenge everywhere"*  
> （万物皆备，四处搜罗）

欢迎来到我的个人杂货铺！这里是一个用来存放日常学习笔记、实用小脚本、代码片段以及各种零碎资源的云端百宝箱。

---

## 📦 仓库内容清单

目前这里主要收录了以下几类东西（持续更新中）：

* **📝 学习笔记**：日常学习编程、软件工具时记录的 Markdown 笔记与踩坑总结。
* **🛠️ 实用脚本**：平时写的一些自动化小工具、配置脚本或常用命令备忘。
* **💡 代码片段**：在各处搜罗到的有趣代码、算法练习或网页小组件。
* **📁 杂项资源**：一些好用的配置文件（如 `.gitignore`、编辑器配置）和参考资料。

---

## 🚀 如何使用

1. **直接浏览**：点击上方对应的文件夹或文件即可在线查看内容。
2. **下载到本地**：如果你对某部分内容感兴趣，可以点击右上角的绿色 **`<> Code`** 按钮，选择 **`Download ZIP`** 打包下载全部内容，或者使用 Git 命令克隆：
   ```bash
   git clone https://github.com
   ```
